# Sola's Writing Portfolio

## Purpose
This writing portfolio is a project that aims to use AI to power how writing can be presented. I plan to use embedding vectors of the writing pieces to inform how they are spatially distributed on the screen. The ultimate goal of this is to move away from a linear, blog-style display to a living, breathing map of how the pieces come together to form my mind.

## Version Updates
**v1.0:**
Created the first prototype of the writing portfolio. The essays are through Supabase, and the website is powered by Vercel. The embeddings are done directly in Supabase but the rest of the AI logic is done directly in JavaScript. Issues include the images not working, some essay cards overlapping, and some hanging off the screen. Future directions include fixing issues and implementing clustering by theme.
